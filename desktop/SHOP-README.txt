Shop POS 1.0.0 for Windows.
This installer puts Shop POS on this Windows user account. It does not need Node, a browser, or an internet connection after installation.
Shop records are stored at %LOCALAPPDATA%\Programs\SalamTech\ShopPOSData\1.0.0. That folder is separate from any Shop POS TEST or evaluation data and is not imported.
The first launch asks for an Admin password and a Salesperson password. Use two different passwords, 8 to 128 characters. Common passwords are rejected. Keep both passwords. They cannot be recovered by the vendor.
Uninstall removes the program and keeps the shop data folder. Do not delete that folder if you still need the records.
This build is linked to the shop Supabase project. Sales and stock still stay on this computer when the internet is down. The service-role key and database password are not included.
This build is not code-signed. Windows may show an unknown-publisher prompt. The installer does not open the app by itself.
